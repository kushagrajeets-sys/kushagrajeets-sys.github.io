My Skills

Technologies and areas I am learning and working with.

1. Game Development

The process of creating video games, from planning gameplay ideas to building features, testing them and improving the overall player experience.

2. Roblox Development

Creating games and interactive experiences on Roblox using Roblox Studio, scripts, game assets and the platform's development tools.

3. Coding

Writing instructions that tell a computer how to perform tasks. Coding is used to create game features, interactions and systems.

4. Lua / Luau Scripting

Using Lua and Roblox's Luau language to script gameplay, player actions, tools, abilities, events and other interactive game features.

5. Programming

Designing and writing logical instructions that make software work. This includes breaking problems into steps and building solutions through code.

6. Game Design

Planning how a game works and feels, including its rules, mechanics, maps, challenges, progression and the way players interact with the game.

7. Problem Solving

Understanding issues, finding their causes and working out practical solutions when developing or improving game features.

8. Debugging

Finding, understanding and fixing errors in scripts or game systems so that features work as intended and the game runs more reliably.

9. Gameplay Systems

Building the systems that make a game function, such as combat, abilities, health, rewards, ranks, player stats and progression.

10. NPC Development

Creating and scripting non-player characters (NPCs), such as bots and villagers. This can include making them move, react to players, follow paths, detect nearby characters and perform actions based on their behaviour.
